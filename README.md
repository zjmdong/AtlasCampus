# AtlasCampus
A 3D twin navigation system.
- This Branch is for development, please commit to this branch during development.
- Only the tested versions can be commit to main branch.
- 在开发时请把相关内容提交到dev这个branch，通过测试后的版本才能提交到main分支。
- 记得commit之后还要push才算完成，不push的话是看不到的。
- commit的description可以直接一键生成，也可以自己写。ai生成的话自己检查一下。
- 每次开发前都要先pull一下最新代码，和其他人同步进度，否则你提交的时候可能会有冲突。


# 计划安排
- 第一周 UI设计稿完成，整理其域所有区域分享链接（调整出生点位置、朝向。遮挡场景禁止进入区域，删除遮挡物、删除模型瑕疵等）每人各完成1/3
- 第二周 确定开发计划、功能需求、程序结构设计等。UI设计稿定稿。开始开发。
- 第三周 完成第一个测试版开发，测试通过。部署到服务器并内测。根据测试结果调整开发计划。
- 第四周 修bug并根据测试反馈，优化代码。发布beta版本，实地部署测试。
